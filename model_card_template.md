## Model Details
- **Developer:** Zachary Senecal
- **Model Date:** October/November 2026
- **Version:** 1.0
- **Model Type:** Scikit-Learn `RandomForestClassifier`

## Intended Use
- **Primary Intended Uses:** This model predicts whether an individual's annual income exceeds $50,000 based on demographic, employment, and educational features derived from the U.S. Census dataset.
- **Primary Intended Users:** Students, CI/CD pipeline automation.
- **Out-of-Scope Use Cases:** This model should not be used for high-stakes automated financial decisions or legal evaluations.

## Training Data
- **Dataset Source:** U.S. Census Income dataset (`census.csv`), extracted from the UCI Machine Learning Repository.
- **Dataset Size:** 32,561 total records split 80/20 into training and testing partitions using stratified sampling based on the target label (`salary`).
- **Feature Set:** Includes both continuous numerical features (e.g., `age`, `fnlgt`, `education-num`, `capital-gain`, `capital-loss`, `hours-per-week`) and categorical features (e.g., `workclass`, `education`, `marital-status`, `occupation`, `relationship`, `race`, `sex`, `native-country`). Categorical features were preprocessed using One-Hot Encoding (`OneHotEncoder`), and target labels were binarized (`LabelBinarizer`).

## Evaluation Data
### Datasets
- **Test Split:** The quantitative evaluation was conducted on a held-out test partition comprising 20% of the total U.S. Census Income dataset (approximately 6,512 samples), obtained via stratified random sampling to preserve the class distribution of the target variable (`salary`).
- **Categorical Slices:** In addition to the aggregate test split, evaluation data includes granular subset views generated by slicing the test data across all unique values of categorical features (such as `workclass`, `education`, `occupation`, and `sex`) to assess performance across diverse demographic and employment subgroups (logged in `model/slice_output.txt`).

### Motivation
- **Generalization Assessment:** The 20% held-out test set provides an unbiased estimate of how well the trained Random Forest classifier generalizes to nonsampled individuals.
- **Robustness & Fairness Auditing:** Evaluating performance across individual categorical slices is motivated by the need to detect potential performance disparities, ensure stable predictive behavior, and identify any demographic or socioeconomic blind spots in the model.

### Preprocessing
- **Feature Alignment:** Categorical features in the evaluation data underwent One-Hot Encoding to match the feature space dimensions expected by the trained model, and column names were stripped of leading whitespace for schema consistency.

## Metrics
- **Precision:** Measures the proportion of positive predictions (`>50K`)
- **Recall:** Measures the proportion of actual positive cases correctly identified by the model
- **F1-Score:** The harmonic mean of precision and recall ($\beta=1$).

### Model Performance Results (Test):
- **Precision:** $0.7299$
- **Recall:** $0.6256$
- **F1-Score:** $0.6738$

## Ethical Considerations
- **Historical Biases:** The U.S. Census dataset contains historical socioeconomic, occupational, and demographic imbalances which introduce systemic biases into the trained classifier.

## Caveats and Recommendations
- **Limitations:** The model uses default hyperparameters for the Random Forest classifier and does not adjust for class weighting, which impacts recall on the minority class (`>50K`).
- **Recommendations:** Future iterations should incorporate hyperparameter optimization (such as tuning tree depth or estimator count) and evaluate fairness metrics across protected attributes before considering any broader applications.
